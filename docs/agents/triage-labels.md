# Triage labels

The skills use five canonical triage roles. This file maps each role to the local tracker label.

| Skill role | Local label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate this issue. |
| `needs-info` | `needs-info` | The reporter needs to provide more information. |
| `ready-for-agent` | `ready-for-agent` | The work is fully specified and ready for an agent. |
| `ready-for-human` | `ready-for-human` | The work needs human implementation. |
| `wontfix` | `wontfix` | The work will not be done. |

When a skill mentions a role, use the matching local label.
