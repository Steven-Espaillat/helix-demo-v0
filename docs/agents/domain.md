# Domain docs

The engineering skills consume this repo as a single-context project.

## Read these first

- Read `CONTEXT.md` at the repo root when it exists.
- Read `CONTEXT-MAP.md` at the repo root when it exists and points to topic-specific context files.
- Read ADRs under `docs/adr/` when they touch the area under work.

If none of these files exists, proceed without raising the absence.

## Use project vocabulary

Use the names that the repo uses for domain concepts. For this repo, current source documents use names such as HELIX, the synthetic bundle, the ten-stage journey, evidence chain, report assembly, validation result, review disposition, gate decision, and export artifact.

## Flag ADR conflicts

If a future output contradicts an ADR, say so in the output instead of replacing the decision silently.
